## About

I am **Cherfaoui Houssam Abderrahmane**, a Statistics & Data Science professional from Algeria with a deep focus on transforming raw data into actionable intelligence. My work spans the full analytical pipeline — from data wrangling and exploratory analysis to machine learning model deployment and interactive business intelligence dashboards.

I specialize in building **data-driven solutions** for real business problems. Whether it is analyzing social media performance for major international brands, engineering predictive models for healthcare datasets, constructing interactive analytics platforms, or shipping full-stack web applications for clients — I approach every project with the rigor of a statistician and the execution mindset of a software engineer.

With a parallel track in **full-stack development** (Next.js, React, TypeScript) and **digital marketing analytics** (Meta Ads, social analytics), I bridge the gap between data science and product — delivering insights that are not only technically sound but commercially impactful.

| Attribute | Details |
|-----------|---------|

This project investigates the data job market through five rigorous research questions: top-paying remote roles, required skill profiles, most in-demand competencies, salary-per-skill benchmarks, and optimal skill stacks. The key finding — the highest-compensating "data analyst" positions are hybrid roles spanning data engineering, ML, and cloud infrastructure. SQL ranked #1 in demand; PySpark and DataRobot command $155K–$208K salaries. Built following Luke Barousse's SQL for Data Analytics curriculum with original analytical extensions.
